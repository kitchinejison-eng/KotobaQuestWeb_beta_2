# ことばクエスト Ver_beta_7｜問題画像JPG完全対応（対象2カテゴリ）

## 対象

ご指定の「認知・理解トレーニング」「失語症・言語トレーニング」で使う問題画像をJPGに統一しました。
以前のご指定どおり「音読・音声認識テスト」「朗読・想起」は変更していません。

| カテゴリ | 課題 | 今回の状態 |

| 認知・理解 | 聴覚的指差し・選択 | 10種類の写真JPGを出題。元のSVG参照表を廃止 |
| 認知・理解 | 聴覚的指示 | 10種類の動作JPGを出題 |

## 新規追加した写真JPG

既存の添付JPGに含まれていなかった以下5点を、単独の被写体が分かりやすい写真画像として制作しました。

- `images/quiz-jpg/naming/hasami.jpg`（はさみ：呼称・ヒント）
- `images/quiz-jpg/cue/kutsushita.jpg`（くつした：ヒント）
- `images/quiz-jpg/cue/kagi.jpg`（かぎ：ヒント）
- `images/quiz-jpg/cue/fuutou.jpg`（ふうとう：ヒント）
- `images/quiz-jpg/cue/makura.jpg`（まくら：ヒント）

「でんわ」は既存のスマートフォンのJPG、「でんしゃ」は既存の電車のJPGを使用しました。
写真には正解の単語を重ねていません。画像の読み込みに失敗した場合は、誤解を招く絵文字ではなく読み込みエラー文を表示します。
