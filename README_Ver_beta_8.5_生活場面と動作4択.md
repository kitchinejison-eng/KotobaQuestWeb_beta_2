# ことばクエスト Ver_beta_8.5 — 生活場面・動作認識の改善

## 変更内容

### 日常会話・コミュニケーション｜生活の場面で伝える

- 生活の写真と場面の説明を見て、言葉カード（4択）かマイクで回答します。
- 以前の「できた」自己申告ボタンと「文字で答える」入力欄を撤去しました。
- 言葉カード・音声認識で共通の正誤判定を行います。音声認識の聞き取り失敗は誤答回数に含めません。
- 1問につき3回不正解で次へ自動進行します。正解した場合も次へ自動進行します。
- 正答率は最初の回答を基準にし、再挑戦の正解・不正解・回答回数をトレーニング記録とExcel出力に反映します。
- 複数の言い方が成り立ちそうな一部の場面を明確化しました。全30問です。

### 失語症・言語トレーニング｜画像の動作を答える

- 旧「動きを見てまねる」を「画像の動作を答える」に改称しました。
- 人物の動作が分かりやすいJPG写真15枚を厳選し、それぞれ異なる動作を出題します。
- 写真を見て「この人は、どのような動きをしていますか？」に4択で答えます。
- ヒント、動作模倣、自己申告の「できた」ボタンはありません。
- 正解は次へ自動進行、不正解は最大3回まで。初回の正答率と回答履歴を記録します。

### 表示・データ

- スマホは選択肢を縦1列、タブレット・PCは横2列に調整しました。
- ボタンにタッチしやすい大きさとキーボードフォーカス表示を設定しました。
- キャッシュを `kotoba-quest-beta85-scene-quiz` に更新し、以前の版が残りにくいようにしました。
- Androidソースのバージョンは `Ver_beta_8.5`（versionCode 129）です。

## 確認内容

- JavaScript構文チェック・自動テスト（JPGファイルの実在・問題と選択肢の重複・不要UIの非表示・初回正答率・3回不正解の扱い）を行いました。
- Android向けのソースコードは同じ修正を反映しています。APKのビルドおよび実機マイクの動作確認は未実施です。

## 注意点

- マイク回答は対応ブラウザまたはAndroidの音声認識環境・マイク権限が必要です。
- 音声認識で文章が別の表記になる場合があります。練習記録は医療上の診断・評価の代わりにはなりません。
