# ことばクエスト ブラウザ版 V108

最初に `START_HERE.html` を開いてください。

ゲーム・レッスンを完了すると、🌸の連続記録がつきます。**その日の初回だけ**、ユーザー指定の黒いガッツポーズピクトグラムが跳ねて花が舞う演出を表示します。演出は数秒で終了するほか、「結果を見る」を押してすぐに閉じることもできます。

演出だけ見たい場合は、タイトルから「トレーニング記録を見る」→「🌸 ガッツポーズ演出を試す」を押してください。記録は増えません。

トレーニング記録のカレンダーやExcelにも🌸の達成日が反映されます。V107の記録は維持されます。

マイク、AI、ホーム画面へのインストールなどはHTTPSまたはlocalhostが必要な場合があります。3Dゲームは初回にThree.jsを外部から読み込むため、インターネット接続が必要です。
