# ことばクエスト Ver_beta_8.6 — 「写字・見写し」日本語OCR試作

## 今回の対象

認知・理解トレーニングの「写字・見写し」のみ。既存のほかの問題・画面・記録は維持しました。

## 修正内容

- ブラウザが日本語の手書き認識APIを提供していなくても、Tesseract.js v7による日本語OCRを試行します。
- ブラウザ版・Android版とも、共通OCRを第一候補として利用します。
- 共通OCRを起動できない、または共通OCRで判読できない場合、Androidアプリ版では従来の端末内認識に切り替えます。したがって、この例外時は認識結果が異なる場合があります。
- 手書きする文字の見本は1〜4文字（漢字・ひらがな・カタカナ）。正誤判定は見本との文字一致で行い、見本の文字をOCRのヒントや制限文字として渡しません。
- OCRの信頼度が低い場合は判読失敗として再入力を案内し、誤答回数を増やしません。
- 正解は次の問題へ自動進行。認識できた文字が異なる場合は最大3回まで挑戦できます。
- 初回正解・再挑戦で正解・3回不正解の分類は、従来のトレーニング記録とExcel出力に引き継ぎます。
- 日本語OCRの認識方式を個々の結果に記録します。

## 認識モデルについての重要な注意

OCRエンジン（JavaScript／WASM）は配布物に含まれていますが、日本語認識モデル `jpn.traineddata` は含まれません。
初回利用時にTesseract.jsの既定の公開CDNからモデルを取得し、可能な環境ではIndexedDBにキャッシュします。そのため初回はインターネット接続が必要であり、完全オフライン保証ではありません。

**Tesseract.jsは印刷体のOCRが主用途で、手書き漢字の認識精度には限界があります。**
採点保留ボタンや自己申告で正解扱いにはしていませんが、文字認識の誤りによる不正解は起こり得ます。
端末・字体ごとに実地テストを行い、必要に応じて日本語手書き専用モデル／OCRサービスへの変更を検討してください。
