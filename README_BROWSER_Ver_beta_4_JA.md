# ことばクエスト ブラウザ版 Ver_beta_4

`index.html` が起動ページです。GitHub Pages等のHTTPSサイトへの配置を推奨します。既存のファイル構成と画像を保ったままアップロードしてください。

**構音筋ビジュアルナビゲーション**は、6種類の構音から毎回5種類を選び、各種類から1つずつランダム出題します。構音の手動選択画面はありません。各問題の側面図と説明が切り替わり、マイク認識結果が確定すると正誤を表示して約1.35秒後に自動進行します。未認識の場合は再試行、発声が難しい場合はスキップが可能です。5問終了後に結果とトレーニング記録が保存されます。

音声認識はブラウザ・OS・マイク権限・通信環境に依存します。短い音は誤認識されることがあるため、認識結果は医療上の発音評価として扱わないでください。
