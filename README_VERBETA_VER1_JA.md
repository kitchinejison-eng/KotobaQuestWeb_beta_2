# ことばクエスト｜構音筋ビジュアルナビゲーション verbeta_ver1

ブラウザ版は、このZIPを展開して `index.html` から起動する構成です。
GitHub Pagesへ配置するときは既存のフォルダ構成を維持してください。
音声認識はブラウザ側の対応・マイク許可・HTTPS接続が必要です。

## この版の変更範囲

V115.1を基に、「発音・発声トレーニング → 構音筋ビジュアルナビゲーション」の画面を
ユーザー提示の3カラムデザインに合わせて再構成しました。ほかのジャンル、会話イベント、
AI会話クイズ、3D、Excel書式、連続記録は引き継いでいます。

### 画面の構成

- 左：6種類の構音を切り替えるメニュー。
- 中央：既存の口腔側面図。部位名ラベルと、グループ別の黄色い強調領域。
- 右：音を選択し、お手本音声、Android/ブラウザの音声認識、次の音、進捗を操作。
- 画面幅が狭い場合は縦向き・タブレットに合わせて配置を自動変更。

### 練習グループ

1. 両唇音：ま・み・む・め・も
2. 唇歯音：ファ・フィ・フェ・フォ・ヴァ（外国語 f/v の口の形の参考）
3. 歯音・歯茎音：た・て・と・な・ね
4. 硬口蓋音：や・ゆ・よ・し・ち（し/ちは歯茎硬口蓋付近）
5. 軟口蓋音：か・き・く・け・こ
6. 声門音：は・へ・ほ

日本語の「ふ」は通常、両唇摩擦音と説明されるため、一般的な唇歯音の例としては扱っていません。
声門音の例でも、口の奥の調音が異なる「ひ・ふ」は除いています。

### マイク・記録

- マイクはV115.1で修正したAndroid標準音声認識と、ブラウザのWeb Speech APIを継続使用。
- 正解扱いは「音声認識で文字を一致させた」ことを表します。実際の舌・唇の動きは測定していません。
- 音の選択画面へ戻って再挑戦しても、1音を2度正解として加点しません。
- 一つのグループを最後まで進めると、従来のトレーニング記録に構音グループ名、
  練習した音、認識結果、スコアを保存します。記録画面では音ごとに ✓ / △ / － を表示します。
- 他の構音グループへ途中で切り替える場合、未完了のセッションは記録しないことを明示しています。
- 文字の数は各グループ3～5音で、5音のグループが主です。

## 検証・注意点

- Node.jsの既存テストと verbeta_ver1 の画面生成・操作テストに合格。
- Android StudioソースにAPKは同梱していません。実機での音声認識・描画検証は未実施です。
- 口腔側面図の強調位置は理解を助ける概略図です。医学的診断や発話器官の実測ではありません。
- Android版は versionCode 117、versionName verbeta_ver1。
