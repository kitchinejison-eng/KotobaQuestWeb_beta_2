# V93 生成AIチャット試験実装

- タイトル画面にV90〜V92で追加されたチャット用ボタンを削除。従来のジャンル選択→「会話・AI」→「生成AIチャット」の導線のみ。
- 既存の定型文型エンジンを生成AIと呼ばない。実際のWebLLM推論でQwen 0.5B系列のモデルを使用し、入力から文章を新しく生成する。
- APIキー・クラウド推論の利用料金は不要。初回はWebLLMランタイム・モデルのダウンロードが必須。データ消去・キャッシュ期限で再取得となる場合がある。
- WebGPU対応ブラウザが必須。Android WebViewは対応状況が端末に依存し、実機動作未検証。AndroidはWebView資産を同期した開発ソースで、ネイティブLiteRT生成AIが組み込まれたものではない。
- テストはJavaScript構文、画面導線、ZIPの整合性のみ。実モデルロードと生成会話はこの環境では検証できていない。
- `index.html`単体での利用はできない（外部JS等のファイルが必要）。HTTPSまたはlocalhostなどの適切な配信環境を使うこと。
- 医療診断や治療として有効性を保証しない。利用者の回答を誤判定・不適切回答する可能性がある。
