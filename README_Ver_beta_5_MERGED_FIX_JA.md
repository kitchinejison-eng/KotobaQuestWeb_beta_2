# ことばクエスト Ver_beta_5：構音筋ナビの復旧＋JPG問題画像

## 修正の原因

先に配布した `Ver_beta_4_JPG` は、構音筋ビジュアルナビゲーションを「ランダム5問＋マイク回答で自動進行」に改修済みだった `Ver_beta_4` ではなく、以前の `Ver_beta_3` を土台に作られていました。そのため、JPG差し替えの際に構音筋ナビが旧仕様へ戻る問題がありました。

今回の `Ver_beta_5` は、**構音筋ナビ改修済み `Ver_beta_4` を原本として使用**し、JPG画像61枚の改修を必要な箇所だけへ追加した統合版です。

## 構音筋ビジュアルナビゲーションの仕様

- 6種類の構音から、毎回異なる5種類を無作為に選び、それぞれの構音の音を1問ずつランダム出題します。
- 問題ごとに、口腔・舌の側面図上の注目部位、構音名、説明を表示します。構音種類の選択ボタンはありません。
- マイク認識結果が確定すると、正誤判定と進捗を表示して、**約1.35秒後に自動で次の問題**へ進みます。
- 5問終了後に結果を表示し、トレーニング記録へ反映します。
- マイクで聞き取れなかった場合は再試行できます。発声が難しい場合のスキップも利用できます。
- 結果が確定しないうちに誤って次の問題へ進まないよう、回答済み状態・課題ID・問題番号を確認して遷移します。

## ブラウザ・Android

- ブラウザ版は `index.html` を使用します。マイクの利用には、通常HTTPSの公開環境かlocalhost、およびマイクの許可が必要です。
- Android版ZIPはAndroid Studio向けソースです。APKではありません。
- 最新の `app.js`、`articulation-random-beta4.css`、`v47-improvements.js`、`v57-task-rebuild.js`、`service-worker.js`、`images/quiz-jpg/` を**一式で**更新してください。1ファイルだけ古いものを残すと旧仕様や画像が表示されることがあります。
- オフラインキャッシュを `kotoba-quest-beta5-articulation-jpg` に更新しています。公開サイトを更新した後は再読み込みし、古い版が出るときはブラウザのサイトデータを再取得してください。

## 動作確認上の留意点

静的ファイル、JPG形式、JavaScript構文、問題数と自動進行のロジックは確認できますが、Android実機でのマイク認識や全画面のタップ操作は実機テストが必要です。音声認識の結果はリハビリの補助であり、医学的に発音の正確さを判定するものではありません。
