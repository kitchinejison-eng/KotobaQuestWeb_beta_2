# ことばクエスト V91 — 端末内会話の操作性修正

- 起動画面に「端末内会話を始める」を追加。設定画面のボタンも残しました。
- 起動直後は自由なおしゃべりから始まり、内容を送信すると画面内に返信を表示します。
- カフェ・買い物など場面練習で、無関係な文章や質問を送ったとき、何でも次のステップへ進む動作を改善しました。
- 通信なし、ライブラリ・AIモデルの追加取得なし。Android WebViewにも同じJSエンジンを同梱しました。
- Service Workerのキャッシュ名をV91へ更新し、変更したJSの版番号を更新しました。

**重要**：会話エンジンは軽量なルールと文脈処理による教材機能です。LLMのように未知の内容へ自由に文章を生成する本物の生成AIモデルではありません。アプリ内に大規模なモデル重みは同梱されていません。AIとして自由生成が必須なら、別途実際のモデルと推論ランタイムの同梱・実機検証が必要です。

ブラウザの文字チャットと単独HTMLは外部通信を行いません。音声読み上げ等、アプリ内の他機能は端末環境に依存する場合があります。Android APKはこの環境ではビルドしていません。
