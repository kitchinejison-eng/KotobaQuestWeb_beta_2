# ことばクエスト Ver_beta_8.3｜写字・見写し 手書き照合

## 今回の改善

- 対象：**認知・理解トレーニング → 写字・見写し**。
- 課題を**1〜4文字**に統一。漢字・ひらがな・カタカナを含む63問から出題します。
- 1文字につき1つの大きい手書き入力欄を表示。スマホは最大2列、タブレットとPCは文字数に応じて最大4列に配置します。
- 指・タッチペン・マウスで書くと、書き終わって約2.3秒後に**自動照合**。手書き認識エンジンから返された文字が見本と一致した場合のみ正解です。
- **「できた」「書いた文字を確認・判定する」「練習として次へ（採点保留）」を廃止**。操作は「1画戻す」「全部消す」に整理しました。
- 不一致は最大3回まで書き直し。3回不一致は不正解として自動で次へ。正解でも自動で次へ。
- **初回正解だけを正答率に反映**。2〜3回目の正解は「再挑戦で正解」として個別に記録します。
- 結果画面と記録・Excel出力に「初回正解」「照合一致」「再挑戦で正解」「3回不一致」を反映します。
- キャッシュを更新して既存バージョンと混ざらないようにしました。

## 対応と制限

- **Androidアプリ版**：Google ML Kit 日本語 Digital Ink Recognition を組み込みました。初回認識時に日本語認識モデル（約20MB）をダウンロードします。ダウンロード後は端末内で処理します。インターネット接続と端末のサービス環境が必要です。
- **ブラウザー版**：Web Handwriting Recognition API が日本語に対応するブラウザーに限り自動採点できます。一般的な iPhone / iPad の Safari や未対応 ChromeOS では日本語の自動採点に対応しません。未対応端末で適当に正解を付ける仕組みは入れていません。
- 手書き認識は字形・書き順・個人差の影響を受けるため、必ずしも正しく読み取るとは限りません。結果は学習用の参考判定です。
