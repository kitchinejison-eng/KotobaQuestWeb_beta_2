# ことばクエスト 開発版 V85

## 更新点
- タイトルとアプリ名に「開発版」を追加。
- 画面切替・起動時のローディング表示を追加。
- ピクトグラム○×3DクイズではThree.jsと初回描画を待ってから操作可能にします。

## ブラウザ版
`index.html` を開いてください。初回起動時は既存仕様のロゴ・会話イベントを表示します。

## Android版
`KotobaQuestAndroid` をAndroid Studioで開いてください。Androidアプリ名は「ことばクエスト 開発版」です。

## 注意
3DクイズはThree.jsをjsDelivrから読み込むため、初回読み込み時にインターネット接続が必要です。通信に失敗した場合は3Dの開始画面にエラーが表示されます。
