# V94（Web版）

- タイトル画面の操作・ボタン配置はV93と同じです。
- 生成AIチャットは「会話・AI」ジャンルのみ。Web版は WebLLM/WebGPU（初回ネット取得必須）。
- 3D ○×ゲームに猫・犬・牛の3D低ポリゴンNPCを配置。
- ねこまるの既存2D画像を通常トレーニングと3D画面に表示。
- 3Dの動物はNPC（非敵対・装飾）で、会話イベントなどのインタラクションは未実装です。
- 生成AIの実モデルの読み込み・返答はWebGPU実機で未検証です。
- 既存の3DゲームはThree.jsを外部CDNから読み込む構成のままです。3Dの初回起動時に通信が必要な場合があります。
- Android用の無料モデル例: https://huggingface.co/litert-community/Qwen3-0.6B-int4 （配布元の利用条件を確認してください）。
