# ことばクエスト ブラウザ版 V115

ブラウザ版V110の整理済み7ジャンル・30課題を、Android版V109由来のAI会話クイズ、マイク、記録、Excel、3D、連続記録と統合しました。

オープニング会話・ことばファンタジーDX・ことばクエストZの会話イベントに、スキップボタンを復活・維持しています。

**開始方法:** ZIPを展開して `START_HERE.html` を開きます。マイク・オフライン保存などを使うにはHTTPSまたはlocalhostで公開してください。GitHub Pagesに置く場合はZIP内の静的ファイルをリポジトリの公開ルートへ配置してください。

**記録:** 端末内の既存トレーニング記録は削除しません。Excelは従来の基本シート構成＋A4印刷用プレビューのままです。
