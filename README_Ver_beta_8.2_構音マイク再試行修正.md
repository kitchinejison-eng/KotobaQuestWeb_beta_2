# ことばクエスト Ver_beta_8.2｜構音筋ビジュアルナビゲーションのマイク再試行修正

## 対象と修正

- **構音筋ビジュアルナビゲーション**で、録音中にマイクボタンをもう一度押した際の無反応を改善しました。
- 録音中の表示を「録音をやり直す」にし、2回目のタップで古い録音を終了、約400ミリ秒後に新しい録音を開始します。
- 15秒以上認識が終わらない場合は、待機を解除して再試行できる状態に戻します。
- マイクのエラー・終了・結果通知が旧録音から遅れて届いても、次の録音の操作状態を壊さないようにしました。
- **Android版**は録音ごとに識別子を付け、JavaとWebViewブリッジの両方で旧通知を区別します。旧録音からの取消操作によって新しい録音を中断しないようにします。
- 修正したJavaScriptの読み込みURLとオフラインキャッシュ名を更新しました。

## 維持した仕様

- ランダムな構音を5問出題し、回答後は自動的に次の問題に進みます。
- 音声認識の正誤判定、構音の側面図、トレーニング記録を維持します。
- スマホ・タブレットの画面レイアウトと3Dゲームには手を加えていません。
- 前回Ver_beta_8.1の写字・見写し判定修正も維持します。

## 検証

- 旧機能の回帰テスト5件、録音再試行テスト1件に合格。
- テストでは2回目の録音開始、遅れて届いた旧録音の終了通知の無害化、15秒タイムアウト解除を確認しました。
- Androidネイティブの開始／終了通知への録音識別子の追加を検査しています。

**未確認：** AndroidアプリのAPKビルド、実際のAndroidスマホ／タブレットでのマイク入力、マイク権限、端末独自の音声認識サービス。Android Studioでビルドして実機確認してください。
