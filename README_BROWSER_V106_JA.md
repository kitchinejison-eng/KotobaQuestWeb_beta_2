# ことばクエスト ブラウザ版 V106

ZIPを解凍し、`START_HERE.html` を開いてください。ゲーム・レッスンを完了すると、🔥「1日目 達成！」の記録がつきます。同じ日の再プレイでは日数は増えず、翌日にも1回完了すると2日連続になります。1日空けると次回の完了時に1日目に戻ります。

通常のクイズ、AI会話クイズ、3Dピクトグラム、コトバ・ダンジョン、朗読・想起、発音、ことばファンタジーDXのクリアが対象です。ブラウザ版とAndroid版の記録は自動同期しません。

マイク、AI、ホーム画面への追加を利用する場合、HTTPSのWebサイトまたは `localhost` での利用を推奨します。単にZIPのHTMLを直接開いた場合は一部機能が制限されます。3Dゲームで外部Three.jsを取得するため、初回はインターネット接続が必要です。
