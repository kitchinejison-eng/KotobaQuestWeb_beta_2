# ことばクエスト 開発版 V89

## V89 の主な更新
- 「会話・AI」に本格的な端末内AI会話を追加。
- ブラウザ版は WebLLM + Qwen2.5-0.5B-Instruct を WebGPU で端末内推論。
- Android版は Google LiteRT-LM + Qwen3-0.6B を CPU で端末内推論。
- APIキー・有料AIサービス契約は不要。会話本文をAI推論サーバーへ送信しない。
- 初回のみ公開モデルをダウンロードし、以後は各端末のキャッシュ／アプリ内保存領域からオフライン推論。
- AIの準備状況はチャット内に表示し、全画面ロード画面は追加しない。
- メダル獲得を全問正解5枚／1問以上正解1枚／全問不正解0枚に統一。
- 3Dクイズのステージ環境を草原・ビーチ・牧場・森からランダム選択。

## オフラインAIの利用条件
- ブラウザ版: 初回モデル取得時はインターネット接続が必要。HTTPSまたは localhost で配信し、WebGPU 対応ブラウザと十分なGPUメモリが必要。モデルとランタイムの取得・キャッシュ完了後、同じサイトオリジンでオフライン利用できる設計。
- Android版: 初回モデル取得時はインターネット接続が必要。Qwen3-0.6Bのモデルファイル（約614MB）をアプリ専用領域へ保存し、以後はLiteRT-LMで端末内推論。十分な空き容量と対応端末性能が必要。
- AIモデル本体は配布ZIP／APKへ同梱していない。配布サイズを抑え、初回に各端末へ取得する方式。
- 対応しない端末ではGPU/CPUメモリ不足等で起動できない場合がある。

## ライセンス・利用
- 使用するQwenモデルは公開配布モデル。Qwen3-0.6BのLiteRT-LM版はApache 2.0表記。
- WebLLMランタイムはオープンソース。個々のモデル配布条件はモデル配布元の条件に従う。

## 検査状況
JavaScript構文、HTML参照、重複ID、manifest、Android XML、ZIP整合性を静的検査する。
Android APKビルド・実機AI推論・WebGPU実機テストはこの生成環境では未実施。利用端末での初回ダウンロードとオフライン動作確認が必要。
