# ことばクエスト ブラウザ版 V115.1

V115の7ジャンル・30課題と会話イベントスキップを維持した小修正版です。

今回の変更：

1. ジャンル選択のカードに、関連する練習分野を表示。
2. 30課題の選択カードに、関連ラベルと「練習すること」を表示。
3. 展開式の説明に、高次脳機能障害・失語症・知的障害・吃音・認知機能の維持を掲載。

ラベルは練習内容との関連を示す目安です。医学的な診断・治療効果や認知症予防の保証ではありません。

Android版の「構音筋ビジュアルナビゲーション」の音声認識修正は、
別添の Android Studio ソース版に含まれます。ブラウザ版は Web Speech API を使用します。

HTMLは index.html から利用できます。GitHub Pagesに配置する場合はファイル構成を保ってアップロードしてください。
