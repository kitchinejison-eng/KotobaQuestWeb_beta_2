# ことばクエスト Ver_beta_8.7 — 写字・見写しの読み取り改善

対象は「認知・理解トレーニング｜写字・見写し」です。ほかのジャンルや正答率・記録仕様は維持します。

## 改善したこと

1. **手書き線のつぶれを解消**：OCR用画像の拡大時、線の幅まで拡大されていた処理を修正しました。入力が小さくても画像化後の線幅は一定です。
2. **別方式で再確認**：まず1文字モードで読み取り、判定が弱い場合は単語モード、さらに細めの線で再認識します。最大3回の認識処理から文字候補を比較します。
3. **読み取れない枠だけ修正**：OCRが読み取り不能とした場合、その1文字の枠だけ消去して再入力できます。他の枠の手書きは残ります。
4. **「この枠を消す」ボタン**：各文字の枠を個別に書き直せます。従来の「1画戻す」「全部消す」も残しています。
5. **正答の不正な補正はしない**：認識器に見本文字を渡しません。認識した文字と見本を一致比較し、誤った文字を正解扱いにしません。判読不能の入力は採点せず、誤答回数に含めません。
6. **共通処理**：ブラウザ版・Android版のWeb画面には同じOCRコードを使います。Android版には従来どおり端末内の手書き認識へのフォールバックもあります。

## GitHub Pagesへの差し替え

GitHub差し替えZIPを解凍したら、**ZIP内のフォルダ名自体を新たな階層として作らず**、以下を公開リポジトリのWebルートに配置します。

| GitHub上の相対パス | 操作 |
| --- | --- |
| `index.html` | 上書き（新OCRスクリプトの読み込み・キャッシュ更新） |
| `v47-improvements.js` | 上書き（読み取り不能時の枠ごとの修正） |
| `service-worker.js` | 上書き（オフラインキャッシュの更新） |
| `ocr/browser-japanese-ocr.js` | 上書き（線幅補正・複数認識パス） |

すでに Ver_beta_8.6 の `ocr/vendor/` 一式が配置済みなら、上の4ファイルだけの差し替えで構いません。
**Ver_beta_8.6 のOCRが未反映の場合は**、ZIP内の `ocr/vendor/` フォルダ全体もアップロードしてください。

コミット後にGitHub Pagesの反映を待ち、ブラウザを強制更新してください。更新後も旧版が出る場合はサイトデータ・Service Workerのキャッシュを確認してください。

## 検証と限界

- コードの構文と既存トレーニングの自動テスト、OCRの疑似認識テストは実行済みです。
- 日本語OCRの基盤は**Tesseract.js v7**で、印刷体向けOCRです。手書き漢字を100%認識できる保証はありません。実際の書字サンプル・端末による精度試験は未実施です。
- JavaScriptとWASMを同梱していますが、日本語モデルは初回にネットワークから取得する必要があります。
- Android版ZIPは**ソースコード**です。APKではありません。
