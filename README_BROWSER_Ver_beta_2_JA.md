# ことばクエスト Ver_beta_2（ブラウザ版）

制作：エジソン・キッチン

横向きは「構音の種類／口腔の側面図／発音問題」の3列、縦向きは「構音の種類→側面図→発音問題→記録」の順に並びます。画面幅と端末の向きで配置が切り替わります。

問題タイルは表示専用になりました。グループ選択は練習を始める前のナビゲーションとして使い、練習中はマイクの結果を確認してから「次の音へ」、または「この問題をスキップ」で順番に進めます。

既存のジャンル、会話イベントスキップ、AIクイズ、Excel、記録、連続記録を保持しています。`index.html` または `logo.html` を起点としてHTTPSで公開してください。ブラウザでの音声認識は端末・ブラウザへの対応とマイク許可が必要です。

※ 音声認識の文字照合だけでは、構音器官の正確な動きを医学的に判定できません。
