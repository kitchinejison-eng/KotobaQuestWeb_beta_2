# ことばクエスト ブラウザ版 V107

`START_HERE.html` から始めます。レッスンやゲームを最後まで完了すると、連続記録が1日分増えます。

タイトル画面の「トレーニング記録を見る」を押すと、連続記録パネルに現在の連続日数と最高記録が表示されます。カレンダーでは🔥が付いた日に完了記録があり、✅は通常の詳細トレーニング履歴がある日です。日別・月別のExcelにも「連続記録」シートが追加されます。

連続記録は端末のブラウザ内に保存されます。Androidアプリとは自動同期されません。3Dゲームの初回起動にはネット接続が必要です。マイクやAIの利用にはHTTPSまたはlocalhostでの実行が必要な場合があります。
