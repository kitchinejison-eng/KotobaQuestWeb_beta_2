# ことばクエスト V90 — 通信不要の端末内会話

## 今回の変更
- ブラウザ版・Android WebView版とも、同じ `offline-conversation-engine.js` を同梱。
- 会話中のCDN import、AIモデルのダウンロード、WebGPU判定、ネイティブのモデル取得を廃止。
- 文字入力からの会話応答は、初回から完全オフライン。空き容量やモデルキャッシュは不要。
- カフェ、買い物、あいさつ、駅、受付、家庭、自由なおしゃべりの場面選択。返答内容・直前の話題などの文脈を使って応答。
- 説明文と画面表示を修正。**この軽量エンジンはルールベースであり、生成LLMではありません。** 自由な質問への知識回答には対応していません。
- AI用の全画面読み込み画面は作成しません。
- AndroidネイティブのLiteRT-LMダウンロードクラスと依存関係を削除。WebView内のJS会話エンジンに統一。

## 使用上の注意
- ブラウザ版の文字チャットはfile://からでも起動できる設計です。Android版はAndroid Studioでビルドするソース一式です。
- 音声読み上げは端末の音声エンジンに依存し、必要な音声データが入っていない端末では初回ネット接続を求められる場合があります。**文字会話には影響しません。**
- 既存の一部ゲーム画面のWeb資産は別ファイルを参照するため、ブラウザ版のフル機能利用にはZIPを展開しフォルダー全体を使ってください。
- `KotobaQuest_OfflineChat_V90_index.html` はスマホで直接開ける、会話画面の単一HTML版です。全ゲームの単一ファイル化ではありません。
- メダルや3Dゲーム等はV89から引き継いでいます。
- Android APKの実機ビルドおよび実際のAndroid端末・ブラウザ操作はこの環境では未実施です。
