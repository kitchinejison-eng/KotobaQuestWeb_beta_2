# ことばクエスト ブラウザ版 V109

トレーニング記録のExcel出力を以前の基本構成に戻し、印刷向けの書式を整えました。

| 種類 | Excelのシート |
|---|---|
| 1日の記録 | 1日の記録、ユーザー設定 |
| 1か月の記録 | 月間集計、実施記録、日別メモ、ユーザー設定 |

ExcelはA4横向き印刷、見出し行の繰り返し、色分け・行間・折り返しに対応しています。出力後の印刷用プレビューはA4縦向きで、横に長い実施記録はカード形式で印刷できます。

花の連続記録はExcelの独立シートをなくしましたが、アプリでの保存・表示・演出には影響しません。

初回は `START_HERE.html` から起動できます。マイク等の機能はHTTPSまたはlocalhostで利用してください。
