# ことばクエスト Ver_beta_6｜スマホ画面・マイク調整版

## 修正した内容

1. **構音筋ビジュアルナビゲーション（スマホ）**：お手本とマイク回答のカードを縦並びにし、狭い画面で文字やボタンが細くなる問題を軽減。説明文・側面図・進捗も小画面向けに整理。
2. **構音筋ビジュアルナビゲーション（タブレット）**：従来の全体配置を維持しながら、マイク関連カードの高さ・折り返し・ボタン幅を調整。
3. **マイク権限（Android）**：許可確認を二重に開始しないようにし、応答が戻らない場合のタイムアウトと再試行時の表示を追加。音声認識サービス・権限・マイク取得のエラーを区別。
4. **ピクトグラム3Dゲーム（スマホ）**：開始画面を縦スクロール可能にしてスタートボタンを確保。問題表示とキャラクター表示を縮小・移動し、操作説明を開閉式に。縦向き時の視野を少し広げ、操作ボタンを日本語に変更。
5. **オフラインキャッシュ**：Ver_beta_6専用キャッシュとURLに更新。端末ごとに古い表示が残る問題を減らす。

## 変更しない内容

- **構音筋ビジュアルナビゲーション**は、構音の種類を選ばせずランダム5問。マイクで回答後、判定して自動的に次へ進む設計を維持。
- 問題に応じた側面図と説明、トレーニング記録、61枚のJPG問題画像は維持。
- **3Dゲームのタブレット・PCレイアウト**は変更しない。タブレットは構音筋ナビのマイク周辺だけに追加調整を適用。
- AIモデルの `huggingface.co` ダウンロード失敗は端末のDNS・ネットワーク接続に関する別件。本版ではネットワーク障害自体を修正していない。

## 配布物

- **Browser**：ZIPを展開し、中の `index.html` をGitHub Pagesなどに配置。
- **Android Source**：Android Studioで開くソースZIP。APKではない。APKを作成する場合はAndroid Studioでビルドする。

## 検証

```bash
node tests/verify-beta5-merge.cjs
node tests/verify-beta6-mobile-mic.cjs
```

上記はコードと構成の自動テストです。**物理スマホ／タブレットでのマイク認識と操作感の実機試験は未実施**のため、公開前に機種別の権限表示・発音判定・自動進行を確認してください。
