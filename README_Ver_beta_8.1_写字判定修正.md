# ことばクエスト Ver_beta_8.1｜写字・見写し判定の修正

## 修正対象

- **認知・理解トレーニング → 写字・見写し** のみ採点と記録の仕組みを変更。
- 他のトレーニング、3Dゲーム、タブレット用レイアウトは基本仕様を維持。

## 修正内容

1. **「少し線を描いて、できましたを押すだけで満点」になる不具合を解消。** 書き込みが少ない状態では判定ボタンを押せません。消しゴムで消した部分は書き込み量に加算しません。
2. 対応端末では日本語の手書き認識結果を取得し、見本と**文字列が一致した場合だけ**画面内の「照合一致」としてカウントします。認識結果に差があるため、判定は補助的なものです。
3. 端末が日本語手書き認識に未対応、読み取り失敗、認識不能の場合は、**「採点保留」**にします。正解・不正解のどちらにも混ぜません。
4. 認識文字が見本と違う場合は一度書き直して再判定できます。2回照合しても一致しない場合は、誤判定を避けるため採点保留にします。
5. 「練習として次へ（採点保留）」を追加。通常の正答率・問題数に採点保留を加算しません。
6. トレーニング結果・記録・Excel出力に「写字照合一致」「写字採点保留」を別項目として記録します。
7. キャッシュ名と変更したスクリプトのURLを更新し、旧版が表示され続ける不具合を防ぎます。

## 大切な制約

ブラウザーやAndroid WebViewの日本語手書き認識機能は、機種・OS・ブラウザーの対応状況によります。**この修正版は、対応していない端末で架空の正答率を表示しません。** すべての端末で自動採点できるようにするには、別途日本語対応の手書き認識エンジン導入・機種テストが必要です。

書く動作の継続と文字の正確さを同じ指標にせず、未判定の問題は支援者が見本と照合してください。
