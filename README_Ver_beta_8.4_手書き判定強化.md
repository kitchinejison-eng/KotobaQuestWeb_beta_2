# ことばクエスト Ver_beta_8.4｜写字・見写し 判定強化

## 方針

手書き文字を見た目だけで採点する仕組みではなく、**既存の日本語手書き文字認識技術（Google ML Kit Digital Ink Recognition）**を使って認識した文字列と見本を照合します。生成AIへの通信・採点依頼は行いません。

## Ver_beta_8.3からの改善

1. **1文字ずつの認識と単語全体の認識を併用**：漢字などの個別文字が紛らわしい場合、書いた全体を文脈付きで再認識します。
2. **誤った正解判定を防止**：単語全体で正しく読めても、個別に認識した文字の候補に見本の文字がない場合は正解にしません。文脈から補うのは候補がある1文字までです。
3. **小さな点や短い線の無効化**：実際の筆跡の長さと広がりを確認し、少量の線のみでは判定を開始しません。
4. **書字中の早すぎる判定を減らす**：最後の筆跡から約3.1秒待って判定を開始します。筆記速度に個人差があるため、極端に長く途中で止めた場合などは判定が早く始まる可能性があります。
5. **1〜4文字の課題、漢字・かな、1文字ごとの大きな入力欄、3回まで再挑戦、初回正答率、記録・Excel出力**は継続します。
6. Android版は **Ver_beta_8.4** としてビルド番号を更新し、ブラウザー版もキャッシュを変更しました。

## ご注意

- **100%の認識精度は保証できません**。書き方や字の崩れ、似た文字、認識モデルの性能により正しい筆跡でも誤認識する場合があります。認識結果の精度は実際の利用者によるテストが必要です。
- Androidアプリ版では、初回に日本語モデル（約20MB）のダウンロードが必要です。ダウンロード後は端末内で認識します。
- ブラウザー版は日本語の Web Handwriting API を利用できる端末のみ採点可能です。未対応のiPhone/iPad等で自動判定を偽装しません。
- Android版は**ビルド用ソース一式**です。APKとしてのビルドと実機テストは、この環境では実施できません。

## 自動検査

- 既存のジャンル、画像、マイクと記録の回帰テスト。
- 1〜4文字問題とスマホ・タブレットのタッチ操作の構造テスト。
- 手書き認識の2経路、複数候補、文脈で誤って正解にしない条件のテスト。
- JavaScript構文検査。
