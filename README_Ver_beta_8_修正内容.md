# ことばクエスト Ver_beta_8｜修正・改善内容

製作：エジソン・キッチン

## 主な修正

1. **発音・発声／失語症・言語トレーニング**
   - 「絵を見て名前を言う」を「画像を見て名前を言う」に統一しました。
   - 「ヒントで言葉を思い出す」は、初めに答えの画像を隠し、必要なときだけ写真ヒントを開けます。
   - 「説明を聞く」は手順を、「問題をもう一度聞く」は「これは何でしょうか？」を、それぞれ違う音声で読み上げます。
   - 正解したら約1.25秒後に次の問題へ自動進行します。不正解は最大3回までで、3回目も不正解の場合は自動進行します。
   - **正答率には最初の1回目の正解だけを加算**します。再挑戦で正解した回数、不正解が3回だった数、総回答回数、ヒントを使った数は別に記録します。
   - マイクが音声を拾えない・接続できない・認識を中止した場合は誤答回数に含めません。入力補助が必要な方向けの文字回答もあります。
   - 問題画面の「ねこまるといっしょにことばの練習」バナーを削除しました。

2. **音声・Android対応**
   - Androidの標準音声読み上げ（TextToSpeech）と画面の読み上げボタンの接続を修正しました。
   - 読み上げボタンを押した場合は、自動読み上げ設定がオフでも再生を試みます。
   - Androidのネイティブ音声認識、マイク許可処理は従来の構成を維持しました。

3. **写真と問題の重複改善**
   - 「動きを見てまねる」20問、「生活の場面で伝える」30問に、**合計50種類の個別JPG場面写真**を割り当てました。従来は少数のSVG画像を何度も共用していました。
   - 「犬」と「手洗い」が同じ写真だった不具合を修正しました。
   - トレーニング用の「かぎ」「くつした」「ふうとう」「まくら」にはJPG画像を指定しています。
   - 「生活の場面で伝える」と「動きを見てまねる」に、それぞれの状況に合う個別ヒントを追加しました。
   - 重複していた駅・会話の設問の一部を、別の場面に修正しました。
   - 旧式の4択プログラムが新しい生活場面・身ぶり画面を上書きする競合を修正しました。
   - コミュニケーションボードでは、問題文が選択肢の答えを直接言わないよう変更しました。

4. **記録とExcel**
   - これまでの記録・端末内保存の仕組みは維持しました。
   - 1日・月間のExcel明細に、再挑戦で正解／3回不正解／回答回数／ヒント使用数の列を追加しました。

## 確認したこと

- Ver_beta_5・6・7の既存検証を引き継いで実行し、すべて通過しました。
- Ver_beta_8検証では、50種類のJPG画像が実在し、それぞれ異なるファイルであること、3回不正解・初回正答率の計算処理、旧式画面との競合解消を確認しました。
- JavaScriptの構文チェックを通過しました。

**端末での実機動作確認は必要です。** 今回の実行環境ではブラウザ自動操作エンジンを起動できず、Android APKのビルド用SDKも存在しなかったため、実機の読み上げ・録音およびAPKインストールまでは確認できていません。Android版はAndroid Studioでビルドできる**ソース一式**です。

## 利用・更新の注意

- **ブラウザ版**：展開した内容を既存のGitHub Pagesの公開フォルダーへ反映すると更新できます。公開前に検証環境で確認してください。サービスワーカーのキャッシュ名とスクリプトのバージョンを更新済みです。
- **Android版ソース**：Android Studioで開き、Gradle同期後にAPKを作成して端末で検証してください。`versionCode=124`、`versionName=Ver_beta_8`です。
- 既存のバージョンとデータのバックアップを取ってから更新してください。ブラウザ版とAndroid版の記録は端末内に個別保存されるため、データの移行操作は別途必要です。
- 写真素材は検証用に新しく制作したものです。生活場面の意味が伝わりにくいものがあれば、該当問題を指定して再調整してください。
