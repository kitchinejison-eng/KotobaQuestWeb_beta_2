# ことばクエスト ブラウザ版 V105

## 使い始める

1. ブラウザ版ZIPを端末に保存して、ZIPをすべて解凍してください。
2. `START_HERE.html` を開き、「アプリを始める」または「3Dクイズで遊ぶ」を押してください。
3. データ保存・マイク・AI・PWAインストールなどの機能を安定して使う場合は、HTTPSのWebサイトとして公開するか `localhost` で起動してください。単純に `file://` で開いた場合、一部の機能は動かないことがあります。

## ホーム画面に追加（ブラウザに公開した場合）

- Android/PC：タイトル画面の「ブラウザ版をアプリとして追加」を押して、表示される案内に従ってください。
- iPhone/iPad：Safariの共有メニューから「ホーム画面に追加」を選んでください。
- 3DクイズはThree.jsを外部サーバーから読み込むため、初回表示時はインターネット接続が必要です。

## V105 3Dキャラクター

- 添付された緑色ピクトグラムを参考に、顔・服のない丸い頭と緑の胴体・両腕・両脚を再構成しました。
- 静止時は腕を斜め上に広げ、移動時は腕を下げて肘を曲げ、左右交互の脚と腕で走ります。
- ダッシュボタン・Shiftキーで走行速度とモーションを速くします。

※ ブラウザ版にはAndroid専用のLiteRT-LMネイティブモデル処理は含まれません。マイクやWebのAI機能は、ブラウザ・接続環境によって利用条件が異なります。
