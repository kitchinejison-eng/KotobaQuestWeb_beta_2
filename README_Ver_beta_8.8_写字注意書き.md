# ことばクエスト Ver_beta_8.8 — 「写字・見写し」開発中の注意書き

対象：「認知・理解トレーニング｜写字・見写し」だけです。

## 変更内容

- 手書き欄の下に、薄い青色でコンパクトな「手書き文字の判定について（開発中）」案内を追加。
- 正しく書いてもAIの認識が失敗する場合があることを明示。
- Google Chrome／Microsoft Edge（最新版）を推奨ブラウザとして案内。
- 文字認識に失敗したときは「文字をうまく読み取れませんでした。…もう一度ゆっくり書いてください。」と表示。
- 読み取れなかった文字の枠だけ書き直す処理を維持。
- 認識失敗は未採点とし、不正解には加算しない仕様を維持。
- スマホ・タブレット・PCの既存レイアウトを維持。注意書きは可変文字サイズ。

手書き認識エンジンはVer_beta_8.7から変更していません。ブラウザを変えるだけで認識精度が保証されるものではありません。

## GitHub差し替え対象

`KotobaQuestWeb_beta_2` リポジトリの、現在のWebサイト用ルートに以下4ファイルを配置してください。

| ファイル | 操作 |
| --- | --- |
| `index.html` | 上書き：CSSとスクリプトの読み込みバージョン変更 |
| `v47-improvements.js` | 上書き：案内表示・エラー文言変更 |
| `v47-improvements.css` | 上書き：案内ボックスのスタイル |
| `service-worker.js` | 上書き：キャッシュ更新 |

GitHub差し替えZIPの最上位フォルダを丸ごと追加するのではなく、その中の4ファイルをリポジトリのルートへ置きます。

**重要：** Ver_beta_8.7 のOCR用ファイル（`ocr/`）がすでに設置されていることが前提です。まだ設置していない環境では、Ver_beta_8.7 の差し替え用ZIPも必要です。

## 確認方法

1. GitHubへコミット後、Pagesへの反映を待つ。
2. ブラウザを強制更新して「写字・見写し」を開く。
3. 手書き欄の下に「手書き文字の判定について（開発中）」があることを確認する。
4. 読み取り不能の際に、特定の枠だけ書き直せることを確認する。

## 検証範囲

既存のブラウザ版自動テストと今回の案内・キャッシュ更新テストは通過。実機でのタッチ操作・手書き精度の試験、GitHubへの公開作業は未実施です。
